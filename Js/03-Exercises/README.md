# JavaScript Exercises

Practice your JavaScript skills with these exercises, organized by difficulty level.

## Structure

### Beginner Exercises

- Basic data type manipulation
- Simple functions and loops
- Conditional logic
- DOM manipulation basics

### Intermediate Exercises

- Array methods and manipulations
- Object-oriented programming
- Asynchronous JavaScript
- Error handling
- Regular expressions

### Advanced Exercises

- Complex algorithms
- Design patterns
- Performance optimization
- Building small applications

## How to Use

1. Each exercise folder contains:

   - A README with exercise requirements
   - A starter JavaScript file
   - Test cases (where applicable)
   - A solution file (hidden in a separate branch)

2. Try to solve the exercises on your own before looking at the solution

3. Run the tests to verify your solution works correctly

## Project Exercises

The final section includes larger project-based exercises that combine multiple concepts:

- Todo List Application
- Quiz Application
- Weather Dashboard
- Shopping Cart
- Simple Blog Engine
