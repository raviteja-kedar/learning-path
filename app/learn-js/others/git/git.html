GitHub and Git Basics

Understanding Git version control system and GitHub workflows

What is Git?

Git is a distributed version control system that tracks changes in source code during software development. It allows multiple developers to work together on projects efficiently by keeping a history of all changes.

How Git Works

Git uses a three-tier architecture for managing your code:

  • Working Directory: Files on your local system
  • Staging Area (Index): Preparation zone for commits
  • Repository: Where Git permanently stores changes as commits

Basic Git Commands

Initial Setup

Command Description
git init Initialize a new Git repository
git clone [url] Clone a repository from remote source
git config --global user.name "[name]" Set your username for commits
git config --global user.email "[email]" Set your email for commits

Basic Workflow Commands

Command Description
git status Check status of working directory and staging area
git add [file] Add a file to the staging area
git add . Add all modified files to the staging area
git commit -m "[message]" Commit changes to the repository with a message
git log View commit history

Branch Commands

Command Description
git branch List all local branches
git branch [branch-name] Create a new branch
git checkout [branch-name] Switch to a different branch
git checkout -b [branch-name] Create and switch to a new branch
git merge [branch-name] Merge specified branch into current branch

Remote Commands

Command Description
git remote add origin [url] Connect local repository to remote repository
git push origin [branch] Push local changes to remote repository
git pull origin [branch] Pull remote changes to local repository
git fetch Download objects and refs from remote without merging

Common Git Workflows

Basic Git Workflow

1. Make changes in working directory
2. Stage changes with git add
3. Commit changes with git commit
4. Push changes to remote with git push

Start by making changes to your files in the working directory.

Feature Branch Workflow

  1. git checkout main - Start from main branch
  2. git pull origin main - Get latest changes
  3. git checkout -b feature-branch - Create & switch to feature branch
  4. Make your changes...
  5. git add . - Stage changes
  6. git commit -m "Add new feature" - Commit changes
  7. git push origin feature-branch - Push to remote
  8. Create pull request on GitHub
  9. After review: git checkout main and git pull origin main

What is GitHub?

GitHub is a web-based platform that uses Git for version control. It provides a graphical interface and collaboration features such as:

  • Remote repositories hosting
  • Pull requests for code review
  • Issue tracking
  • Project management tools
  • Wikis and documentation
  • Actions for CI/CD workflows
