Variable Declarations in JavaScript

JavaScript provides three ways to declare variables: var, let, and const. Each has different scoping and hoisting behavior that affects how and when they can be accessed.

var

var is the original way to declare variables in JavaScript. Variables declared with var are function-scoped, meaning they are accessible throughout the function they are defined in. 

function example() {
  var x = 10;
  if (true) {
    var x = 20; // Same variable, x is now 20
    console.log(x); // 20
  }
  console.log(x); // 20
}
Note: var declarations are hoisted to the top of their scope, but only the declaration, not the initialization. This can lead to unexpected behavior.

let

let was introduced in ES6 (2015) and provides block-scoped variables. Variables declared with let are only accessible within the block they are defined in. 

function example() {
  let x = 10;
  if (true) {
    let x = 20; // Different variable from the outer x
    console.log(x); // 20
  }
  console.log(x); // 10
}

const

const was also introduced in ES6 and works like let (block-scoped), but with one important difference: variables declared with const cannot be reassigned after initialization. 

function example() {
  const x = 10;
  // x = 20; // Error: Assignment to constant variable
  
  // However, if x is an object or array, its properties can be modified
  const user = { name: 'John' };
  user.name = 'Jane'; // This works
}

Best Practices

Modern JavaScript favors:

  • Using const by default for variables that won't be reassigned
  • Using let for variables that will be reassigned
  • Avoiding var in new code to prevent scope confusion
Remember: Both let and const have temporal dead zones (TDZ), meaning they can't be accessed before declaration, unlike var.
