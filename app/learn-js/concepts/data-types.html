Primitive Types vs Reference Types in JavaScript

JavaScript values are categorized into primitive types and reference types. Here's a clear breakdown with explanations and examples:

Primitive Types

Primitive types are the most basic data types in JavaScript. They are immutable and represent a single value. There are seven standard primitive types:

Primitive Type Description Example typeof Result
Number Numeric values (integers, floats, special values like NaN, Infinity) let age = 30; 'number'
String Sequences of characters let name = "Alice"; 'string'
Boolean Logical values: true or false let isActive = false; 'boolean'
Null Explicitly no value (intentional absence of any object value) let data = null; 'object' (quirk)
Undefined Variable declared but not assigned a value let x; 'undefined'
Symbol Unique, immutable identifiers (ES6+) let id = Symbol("id"); 'symbol'
BigInt Arbitrarily large integers (ES2020+) let big = 12345678901234567890n; 'bigint'
Key Points:
  • Primitives are not objects and have no methods or properties.
  • They are compared by value.
  • Strings behave like objects temporarily so you can use methods, but are still primitives.

Reference Types

Reference types are objects. They can store multiple values and are mutable.

Reference Type Description Example typeof Result
Object Collection of key-value pairs let person = { name: "Bob" }; 'object'
Array Ordered list of values (special kind of object) let nums = [1, 2, 3]; 'object'
Function Callable objects (also a type of object) function greet() {} 'function'
Key Points:
  • Reference types are compared by reference (not by value).
  • Arrays and functions are technically objects.
  • Objects can have properties and methods.

Examples

// Primitive types
let score = 100;             // Number
let greeting = "Hello";      // String
let isOnline = true;         // Boolean
let nothing = null;          // Null
let notDefined;              // Undefined
let uniqueId = Symbol();     // Symbol
let hugeNum = 123n;          // BigInt

// Reference types
let user = { name: "Jane" }; // Object
let colors = ["red", "blue"]; // Array
function sayHi() {           // Function
  console.log("Hi!");
}

Summary Table

Type Category Types Included How Stored/Compared
Primitive Number, String, Boolean, Null, Undefined, Symbol, BigInt Stored by value, immutable
Reference Object, Array, Function Stored by reference, mutable
In short:
  • Primitive types are the simple, immutable building blocks (like numbers and strings).
  • Reference types are objects, arrays, and functions—complex structures that can hold multiple values and are mutable.

This distinction is fundamental for understanding how variables behave and how data is managed in JavaScript.
